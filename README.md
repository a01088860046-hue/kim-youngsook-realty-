# 김영숙부동산 공식 홈페이지

김영숙 대표가 직접 운영하는 부동산 매물 안내 홈페이지입니다.

- 대표 전화: 010-2167-2400
- 소재지: 대구광역시 동구 신암북로11길 6
- 주 중개 대상: 동대구역 센텀화성파크드림
- 전문 분야: 대구시 재개발·재건축

## 동구 아파트 데이터 자동 갱신

GitHub Actions가 매일 오전 6시 30분(한국시간)에 국토교통부 실거래가 공개자료를 다시 수집합니다. 정상적으로 생성된 데이터가 변경되면 자동 커밋 후 GitHub Pages를 다시 배포합니다.

API 인증키는 저장소의 Actions 비밀값 `DATA_GO_KR_API_KEY`로만 관리하며 소스코드와 공개 파일에는 저장하지 않습니다.

## 공개 블로그 자동 갱신

GitHub Actions가 매일 오전 7시 15분(한국시간)에 김영숙부동산 네이버 블로그의 공개 RSS를 확인합니다. 새 글이 발행되면 `content/blog-posts.json`을 갱신하고 홈페이지의 최신 완성 글 3개를 자동으로 바꿉니다.

방문자는 공개 글과 카드뉴스를 열람할 수만 있습니다. 홈페이지에는 작성·수정·삭제 기능이 없으며, 자동화 설정과 공개 파일을 변경할 수 있는 권한은 GitHub 저장소 쓰기 권한을 가진 계정으로 제한됩니다.

인스타그램 카드뉴스는 공식 API 접근 권한 없이 자동 수집하지 않으며, 홈페이지에서는 공식 `@budongsan9dan` 계정으로 연결합니다.

매물정보와 관련 제도는 변경될 수 있으므로 계약 전 최신 내용을 확인합니다.
